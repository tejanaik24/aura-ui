# Aura UI

UI Components + Templates for AI-Assisted Developers

## Features

- 60+ React components built with Tailwind CSS
- Full website templates ready to customize
- Built for Claude Code, Cursor, and vibe coders
- Copy and paste into your project

## Getting Started

## Usage

```bash
npx aura-ui add button
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
